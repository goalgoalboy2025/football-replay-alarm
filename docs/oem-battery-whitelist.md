# 国产 ROM 后台保活配置清单（荣耀 / 小米 / OPPO / vivo / 华为）

> 装上 App 后，请按你的机型找到对应章节逐项配置。**全配完才能保证提醒准时弹出**。
> 不配置的话，最常见的现象是：周一周二还正常，周三开始通知不弹了——这是被系统"冷冻"了。
>
> 为什么会这样：本 App 的提醒依赖 `AlarmManager.setAlarmClock()` 在指定时刻唤醒。但国产 ROM
> 会在熄屏后把"不活跃"的 App 冻结或深度休眠，精确闹钟也会被延迟甚至丢弃。以下配置就是把
> 本 App 加入各厂商的"豁免名单"。

## 荣耀（MagicOS）

> 以下 5 项以 MagicOS 10 实机菜单为准，其他版本菜单位置可能略有差异。

### 项目 1：应用启动管理（最关键）

```
设置 → 应用和服务 → 应用启动管理
```

1. 找到 **看球不熬夜闹钟**
2. 关闭 **「自动管理」**（默认是开的）
3. 弹出的三个细项**全部勾选**：
   - ✅ 允许自启动
   - ✅ 允许关联启动
   - ✅ 允许后台活动

> 这一项是 90% "通知收不到"问题的根因。

### 项目 2：电池策略设为不受限

```
设置 → 应用 → 应用管理 → 看球不熬夜闹钟 → 电池
```

把电池策略改为 **「不受限制」**（或「不允许优化」）。

> MagicOS 默认对所有 App 启用"自适应"省电，会延迟唤醒，导致开球前 15 分钟提醒可能晚 5-10 分钟。

### 项目 3：关闭智能省电与应用冷冻

```
设置 → 电池 → 智能省电
```

在"参与省电"列表中找到本 App 并**移除**。

```
设置 → 应用 → 应用管理 → 看球不熬夜闹钟
```

找到 **「应用冷冻」**（菜文名因子版本而异），关闭。

> MagicOS 的"应用冷冻"会把 7 天没主动打开过的 App 暂停，必须排除。

### 项目 4：通知权限与重要级别

```
设置 → 通知和状态栏 → 应用通知管理 → 看球不熬夜闹钟
```

- 总开关：✅ 允许通知
- 渠道 **「直播提醒」** → 设为 **「重要通知」**：横幅 / 锁屏 / 震动 / 响铃全开
- 渠道 **「录播提醒」** → 「常规通知」即可
- 渠道 **「周赛程汇总」** → 「静默通知」即可

> App 会在每次启动时自动把三个渠道修补为上述重要度（渠道重要度建成后系统不允许 App 再改，
> 所以荣耀上偶尔需要手动确认一次）。

### 项目 5：锁屏与后台权限

```
设置 → 应用 → 应用管理 → 看球不熬夜闹钟 → 权限
```

- ✅ 通知（POST_NOTIFICATIONS）
- ✅ 闹钟和提醒（SCHEDULE_EXACT_ALARM）
- ✅ 显示在其他应用上层（悬浮窗，保证锁屏完整显示）

### MagicOS 自动重置陷阱

以下情况会**静默重置**应用启动管理：系统更新后、App 升级安装后、长时间未使用、存储空间不足自动清理时。

对策：App 内置「提醒健康检查」页（设置 → 提醒健康检查），每次打开时检测权限是否被回收，被回收会明确提示。

## 小米（MIUI / HyperOS）

```
设置 → 应用设置 → 应用管理 → 看球不熬夜闹钟
```

1. **自启动**：打开 ✅
2. **省电策略** → 「无限制」
3. **通知权限**：允许，且「提醒类通知」设为重要
4. 神隐模式（旧版 MIUI）：对本 App 关闭
5. `设置 → 电池` → 右上角齿轮 → **关闭「省电优化」对本 App 的深度管控**

> 小米常见现象：锁屏后通知只振动不出声 → 检查渠道「直播提醒」的铃声是否为空（App 已显式
> 指定 USAGE_ALARM 铃声，若仍无声请把渠道手动设为重要通知）。

## OPPO（ColorOS）

```
设置 → 应用 → 应用管理 → 看球不熬夜闹钟 → 电池
```

1. **允许完全后台行为 / 不优化**
2. `设置 → 电池 → 更多设置 → 应用快速冻结`：移除本 App
3. `设置 → 应用 → 应用启动管理`：允许自启动 + 关联启动 + 后台活动
4. 最近任务里下拉本卡片 → **锁定**（防一键清理杀后台）

---

## vivo（OriginOS / Funtouch）

```
设置 → 应用 → 应用管理 → 看球不熬夜闹钟
```

1. **电池** → 「允许后台高耗电」
2. **权限** → 「后台弹出界面」+「锁定后台」（最近任务下拉锁定）
3. `i 管家 → 应用管理 → 权限管理` → 自启动 ✅
4. `设置 → 电池 → 后台功耗管理`：对本 App 关闭智能限制

---

## 华为（EMUI / HarmonyOS）

```
设置 → 应用和服务 → 应用启动管理 → 看球不熬夜闹钟
```

1. 关闭「自动管理」，手动三开：自启动 / 关联启动 / 后台活动
2. `设置 → 电池 → 更多电池设置` → 关闭「休眠时始终保持网络连接」相关限制对本 App 的管控
3. 手机管家 → 启动管理：本 App 设为「手动管理」
4. HarmonyOS 的「纯净模式」不影响本 App，但「智能省电」会限制——将本 App 加入「不受限制」

---

## 配置完成后：3 个验证测试

1. **测试 A（5 秒通知）**：设置 → 高级 → 「测试通知」，锁屏等 5 秒，应有横幅+铃声
2. **测试 B（30 分钟闹钟）**：设置 → 高级 → 「测试 30 分钟闹钟」，锁屏放置，30 分钟后应响
3. **测试 C（关键 8 小时）**：睡前确认 App 内有次日早晨的录播提醒，睡一觉，看早晨能否准时响

**测试 A 过、B 不过** → 电池策略受限（重做各厂商第 2 项）
**头几天正常、之后失效** → 应用冷冻/省电名单（重做第 3 项）
**3 项全过 → 配置成功。**

## 常见故障速查

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 5 秒测试都收不到 | 通知权限没开 | 重做通知权限项 |
| 5 秒可以、30 分钟不行 | 电池策略受限 | 重做电池策略项 |
| 头几天正常、之后失效 | 应用冷冻 / 智能省电 | 重做冷冻排除项 |
| 解锁才弹，锁屏不弹 | 锁屏通知未授权 | 通知渠道设重要 + 悬浮窗权限 |
| 提醒晚 5-10 分钟 | 没有授予精确闹钟 | 授予「闹钟和提醒」权限 |
| 重启手机后失效 | 启动管理被自动重置 | 重做自启动三项 |
